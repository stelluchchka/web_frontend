## Описание проекта

Фронтенд-часть системы для заказа блюд быстрого питания предоставляет пользовательский интерфейс для взаимодействия с системой. Он включает в себя веб-приложение, разработанное с использованием библиотеки React, и нативное приложение на React Native. Фронтенд взаимодействует с backend-частью системы через REST API.

## Основные функции

- **Просмотр блюд**: Гости могут просматривать список блюд с фильтрацией.
- **Создание заказов**: Авторизованные пользователи могут добавлять блюда в заказ, редактировать и удалять их.
- **Управление заказами**: Пользователи могут отслеживать статус своих заказов, а менеджеры могут одобрять или отклонять заказы.
- **Аутентификация и авторизация**: Пользователи могут регистрироваться, входить в систему и выходить из нее.

## Технологии

- **Язык программирования**: JavaScript (ES6+)
- **Библиотека для веб-приложения**: React
- **Библиотека для нативного приложения**: React Native
- **Стилизация**: CSS, SCSS
- **Управление состоянием**: Redux
- **Маршрутизация**: React Router

## Установка и запуск

### Предварительные требования

- Убедитесь, что у вас установлен [Node.js](https://nodejs.org/) версии 14 и выше.
- Установите [npm](https://www.npmjs.com/) или [yarn](https://yarnpkg.com/).

### Шаги для запуска

1. **Клонируйте репозиторий:**

```bash
git clone https://github.com/stelluchchka/web_frontend.git
cd web_frontend
```

2. **Установите зависимости:**
```bash
npm install
```
3. **Запустите сервер разработки:**
```bash
npm start
```
4. **Приложение будет доступно по адресу:**
http://localhost:3000

## API

Фронтенд взаимодействует с backend через следующие API-методы:

### Блюда

- GET /api/dishes/: Получить список блюд с фильтрацией.
- GET /api/dishes/int:pk/: Получить подробную информацию о блюде.

### Заказы

- GET /api/orders/: Получить список заказов с фильтрацией.
- GET /api/orders/int:pk/: Получить информацию о заказе.
- PUT /api/orders/int:pk/put/: Изменить заказ.
- PUT /api/orders/accept/: Изменить статус заказа (пользователем).
- PUT /api/orders/int:pk/confirm/: Изменить статус заказа (модератором).
DELETE /api/orders/int:pk/delete: Удалить заказ.

### Аутентификация

- POST /user/login/: Аутентификация.
- POST /user/logout/: Выйти из системы.
- POST /user/: Создать новый аккаунт.
- POST /user_info/: Получить информацию о пользователе.

## Компоненты

### Навигационная панель

- Войти: Переход на страницу входа. Доступно только для гостей.
- Зарегистрироваться: Переход на страницу регистрации. Доступно только для гостей.
- Выйти: Выход из системы. Доступно только для авторизованных пользователей.
- Открыть список блюд: Переход на страницу блюд. Доступно только для клиентов.
- Открыть заказ-черновик: Переход на страницу заказа. Доступно только для клиентов с заказом.
- Открыть список заказов пользователя: Переход на страницу заказов. Доступно только для авторизованных пользователей.
- Открыть таблицу блюд для редактирования: Переход на страницу управления блюдами. Доступно только для менеджеров.
- Открыть все заказы: Переход на страницу всех заказов. Доступно только для менеджеров.

### Страница входа

- Форма входа: Поля для ввода email и пароля.
- Кнопка "Войти": Отправляет запрос на аутентификацию.
- Кнопка "Зарегистрироваться": Переход на страницу регистрации.

### Страница регистрации

- Форма регистрации: Поля для ввода email, имени, фамилии и пароля.
- Кнопка "Зарегистрироваться": Отправляет запрос на регистрацию.
- Кнопка "Войти": Переход на страницу входа.

### Страница блюд

- Список блюд: Отображает карточки блюд с изображением, названием, тегом, постом повара и стоимостью.
- Фильтры: Позволяют фильтровать блюда по названию, тегу и цене.
- Кнопка "Добавить в заказ": Добавляет блюдо в заказ. Доступно только для авторизованных пользователей.
- Кнопка "Подробнее": Переход на страницу подробной информации о блюде.

### Страница подробной информации о блюде

- Информация о блюде: Отображает изображение, название, стоимость, описание, имя и фото повара, вес, энергетическую ценность, срок годности и состав блюда.

### Страница заказа

- Таблица заказа: Отображает список блюд в заказе с возможностью удаления и изменения количества.
- Кнопка "Удалить заказ": Удаляет заказ. Доступно только для авторизованных пользователей.
- Кнопка "Сформировать заказ": Отправляет заказ на проверку. Доступно только для авторизованных пользователей.

### Страница списка заказов

- Таблица заказов: Отображает список заказов с информацией о статусе, пользователе, дате создания, дате формирования, дате завершения и результатах оплаты.
- Фильтры: Позволяют фильтровать заказы по пользователю, диапазону дат и статусу.
- Кнопка "Подробнее": Переход на страницу подробной информации о заказе.

### Страница управления блюдами

- Таблица блюд: Отображает список блюд с возможностью добавления, редактирования и удаления.
- Кнопка "Добавить новое блюдо": Переход на страницу добавления блюда.
- Кнопка "Изменить блюдо": Переход на страницу редактирования блюда.
- Кнопка "Удалить блюдо": Удаляет выбранное блюдо.

### Страница добавления/редактирования блюда

- Форма блюда: Поля для ввода информации о блюде, включая изображение, название, тег, категорию, стоимость, описание, имя и фото повара, вес, состав и срок годности.
- Кнопка "Сохранить": Сохраняет изменения или добавляет новое блюдо.
